Score rationale, where it is not obvious:
- **KELORA trademark 4, not 5:** INNORPI, WIPO and EUIPO are unchecked, and there are near marks in other classes.

- **NASAQ trademark 2:** a descriptive common word, plus NASDAQ proximity in the financial sector.

## 5. Recommendation (provisional)

**Strongest candidate on current evidence: KELORA.** It is the only candidate with:
- no live conflicting mark or software product found
- a probably purchasable .com
- no meaning problems in Arabic, French or English

**TELORA is not recommended:** a software product of the same name already exists, and both .com/.net are held. **NASAQ** has the best Arabic meaning. However, its common-word status and NASDAQ proximity make it risky as the **company** name for a financial-sector product. It could still serve as a product or feature name if the attorney agrees.
