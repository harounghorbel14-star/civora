## Status values

| Status | Meaning |
|---|---|
| **Text verified [V]** | Article read in the official text or an official copy (source given) |
| **Text verified [V], application unclear** | The text is clear, but whether or how it applies to CIVORA needs counsel |
| **Secondary only [P]** | Known only from press, law firms or databases; official text not read in this pass |
| **Not verified [U]** | No reliable source found |
| **Pending legislation** | A reform is under parliamentary review; current law still applies |
